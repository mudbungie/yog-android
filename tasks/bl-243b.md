The mobile half of closing the ergonomic loop: agents must be able to render the android client and read PNGs of it without a physical device.

Shape: a make target / script that (1) boots a headless emulator (AVD), (2) installs the debug build, (3) walks a set of named screens (main, chat, settings at minimum), (4) captures each via 'adb exec-out screencap -p' plus a uiautomator accessibility dump beside every PNG, (5) tears down. Outputs land where an agent can Read them.

Notes:
- The emulator route deliberately dodges the physical-device traps (the rotating adb port that blocked install, restricted settings). Read this repo's AGENTS.md / trap ledger before starting; some ledger entries may still apply (JNI classloader).
- The yog store carries bl-8741 (named deterministic fixture worlds a client can dial). Point the client at one of those when available; a canned/recorded endpoint is an acceptable stand-in — do not block on it.
- First standing assertion once capture works: the settings surface is reachable from the main screen — the accessibility dump makes that mechanical, and it is exactly the defect class this exists to catch.
- PNGs are for agent eyes; only structural assertions (reachability, presence) gate. No golden-image pixel diffs.

Verify premises against the tree before building — this body was written from memory, not a fresh read of this repo.
