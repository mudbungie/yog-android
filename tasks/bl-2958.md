PASTE-READY REPORT for Google IssueTracker (Android Game Development Kit component; library androidx.games:games-activity:4.4.0):

Title: GameTextInput InputConnection.onKey calls restartInput() on every key, breaking IME delete-repeat

Description:
com.google.androidgamesdk.gametextinput.InputConnection installs itself as the surface view's OnKeyListener. Its onKey, after a successful processKeyEvent, unconditionally calls InputMethodManager.restartInput() (visible in logcat as closeConnection followed by a rebuild).

Consequence: soft keyboards send backspace as KEYCODE_DEL via InputConnection.sendKeyEvent, and their long-press delete-repeat is a loop run against the connection that dispatched the first delete. That first delete destroys the connection (restartInput), so the repeat loop never starts: long-pressing backspace deletes exactly one character in every GameActivity app. A plain EditText never restarts input on a keystroke. Reproduced with games-activity 4.4.0 and Gboard on a Pixel running SDK 35; setting a rich EditorInfo (TYPE_CLASS_TEXT) does not change it, and no editor-state mirroring fixes it, because the defect is the connection teardown itself.

Suggested fix: drop restartInput() from onKey, or make it conditional on state the IME cannot already observe through updateSelection/stateUpdated. stateUpdated() + imm.updateSelection() already inform the IME of the edit; the restart adds nothing a per-key teardown is worth.

Workaround we ship meanwhile (public API only): install a replacement OnKeyListener after the InputConnection's constructor has installed its own; for KEYCODE_DEL with a collapsed selection call deleteSurroundingTextInCodePoints(1, 0), endBatchEdit() (which invokes the library's private stateUpdated()), then imm.updateSelection(...), and swallow the event; delegate every other key to the stock listener. Delete-repeat then works (~52 ms/char). Reaching the package-private mInputConnection requires one helper class declared in package com.google.androidgamesdk — which is itself a sign the repair belongs in the library.
