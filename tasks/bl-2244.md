Operator ruling: the app spells it **enroll** / **enrollment**, not the British `enrol`/`enrolment`. The tree carries the British spelling in prose, in identifiers and in one file name (`src/shell/enrol.rs`).

Sweep it everywhere at once — file names, module declarations, identifiers, doc comments, README and DESIGN prose — so no second spelling survives to be grepped for later. `src/shell/enrol.rs` renames to `src/shell/enroll.rs` and `src/bootstrap.rs`'s `Enrolment` type renames with it.

One spelling is the whole deliverable: two spellings of one word is the same defect as two authorities for one fact.
