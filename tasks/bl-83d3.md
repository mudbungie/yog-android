What is left for this repository: the host loop (src/host/serve.rs) ignores the key, so a host that is still alive when another process bearing its certificate advertises reads an empty hold, asks again, is refused, waits, and advertises — taking the queue back. thrall bl-1f02 is the model: read the key, end the host with a sentence naming a newer activation, do not dial again.
