Each dial started 2–3 concurrent ladders on the same NoodleZoo entry (the roster read, the conversations read, the attention fetch — each dial site climbs its own ladder). Reframe, not a workaround: one ladder per entry — a single dial in flight per pairing, every other caller waits on it and shares the line it lands (the held line is per entry already, rung 1); a second concurrent rendezvous on the same entry is never right because the slot holds one call.
