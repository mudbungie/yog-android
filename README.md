# yog-android

The phone seat for [yog](https://github.com/mudbungie/yog): an Android client
of yog's remote boundary (yog `docs/REMOTE.md`) — a wire client speaking
`Act | Ask` frames over mTLS to an engine that runs elsewhere.

Founding commit; the table (gates, CI, discipline) lands through `bl`-tracked
work. See AGENTS.md once it exists.
